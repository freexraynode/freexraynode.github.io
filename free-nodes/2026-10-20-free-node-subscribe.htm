初识 Quantumult：它为何值得你关注？

在深入购买流程之前，我们有必要先对 Quantumult 有一个清晰的定位。简单来说，Quantumult 是一款运行在 iOS（iPhone 和 iPad）平台上的网络代理与网络优化工具。它的核心功能在于允许用户通过自定义配置或订阅远程规则，将设备产生的网络流量按照既定策略转发到位于不同地理位置的代理服务器上。这样一来，你便可以实现跨越地域限制访问全球内容、加密网络通信以保护隐私、甚至通过分流规则让国内外网站访问速度都达到最优。

与市面上其他同类工具相比，Quantumult 最引以为傲的便是其强大的脚本支持能力和高度模块化的界面设计。它不仅仅是一个“开关”式代理，更像是一个微型的网络操作系统。你可以为它编写复杂的 JavaScript 脚本，实现自动签到、去广告、修改响应数据等高级玩法。这种极高的可玩性，使得 Quantumult 在技术社区中拥有极高的声望，被誉为“网络工具中的艺术品”。当然，高自由度也意味着有一定的学习成本，但这恰恰是它魅力所在。

第一章：购买前的准备工作——磨刀不误砍柴工

在你兴冲冲地打开 App Store 搜索 Quantumult 之前，有几项准备工作能帮你避免后续的许多麻烦。

其次，准备一个可用的 Apple ID。Quantumult 的下载与购买完全依托于苹果的 App Store 生态。你需要确保你的 Apple ID 已登录，并且已经开启了双重认证或至少绑定了有效的支付方式（如支付宝、微信支付或信用卡）。由于该应用在部分国家和地区的 App Store 中可能因政策原因被下架或限制搜索，你还需要确认你的 App Store 账号区域能够正常搜索到该应用。如果搜索不到，通常需要切换至美区或港区等账号，这需要你自己权衡并解决账号归属问题。

最后，明确你的需求。Quantumult 本身是一个付费应用，且采用的是一次性买断制（而非订阅制）。这意味着你只需在下载时支付一次费用，即可永久使用该应用的核心功能。但请注意，应用内部可能提供一些附加的“高级功能”或“扩展订阅”作为可选项，这部分内容我们将在下一节详细拆解。提前想清楚你只是需要基础的代理功能，还是想体验所有高级特性，这有助于你判断是否需要额外的内购支出。

第二章：Quantumult 怎么买？——两大途径详细拆解

这是本文的重中之重。购买 Quantumult 实际上分为两个层面：购买应用本身（即从 App Store 下载）和购买或获取可用的代理订阅服务（这是让工具真正发挥作用的关键）。很多人混淆了这两者，导致买了应用却无法使用。

途径一：购买应用本体——App Store 下载与付费

这是最基础的一步。请按照以下步骤操作：

  1. 打开 App Store：在你的 iPhone 或 iPad 上，找到并打开蓝色的 App Store 图标。
  2. 精准搜索：在底部导航栏点击“搜索”，然后在搜索框中输入“Quantumult”。这里需要特别留神，因为搜索结果中可能会出现诸如“Quantumult X”这样的名称。实际上，Quantumult X 是原版 Quantumult 的升级版或独立版本，目前开发者 Yan Hu 主要在维护 Quantumult X。如果你想要获得最新功能和最活跃的社区支持，建议直接搜索并下载 Quantumult X。在本文后续的叙述中，我们统一以 Quantumult X 作为代表进行讲解。
  3. 核对开发者信息：点击搜索结果中由 Yan Hu 开发的应用图标。请务必核对开发者名称，以免下载到仿冒或高仿的山寨应用。
  4. 获取与购买：点击应用详情页右侧的“获取”按钮（或显示价格，如“¥30”或“$4.99”）。如果你的 Apple ID 未设置免密支付，系统会通过 Face ID、Touch ID 或侧边按钮要求你确认购买。确认后，应用便会开始下载。
  5. 完成安装：下载完成后，你的主屏幕上会出现一个带有网络节点图形、风格偏极简的图标，这就是 Quantumult X。

重要提示：这一步的付费是付给苹果公司的，用于购买应用的使用权。请务必记住，你购买的只是这个“空壳”工具，它本身并不包含任何可用的代理服务器节点。这就像你买了一台精密的收音机，但它本身不发射信号，你需要自己找电台。

途径二：购买代理订阅服务——让工具“吃饱”

这是购买流程中真正具有技术含量且容易让人困惑的一步。Quantumult 本身不提供任何翻墙线路，你需要自行购买来自第三方服务商的“机场订阅”或自建服务器。

  1. 选择合适的服务商：市面上有大量提供代理订阅服务的平台，通常被称为“机场”。你需要根据自己的需求（如流量大小、线路速度、价格预算）选择一家信誉良好、稳定性高的服务商。这通常需要你在网络社区中做一些调研，寻找口碑较好的推荐。
  2. 购买订阅套餐：访问你所选服务商的官方网站，注册账号并购买相应的套餐。套餐一般会按照时长（月付/季付/年付）和流量（GB/TB）来划分。支付方式通常支持支付宝、微信或 USDT 等加密货币。
  3. 获取订阅链接：购买成功后，在服务商的用户中心或控制面板中，你会找到一个名为“订阅链接”或“一键订阅”的字符串。通常是一个以 https:// 开头的长网址。请注意，这个链接是你的身份凭证，包含了你的专属配置信息和节点列表，务必妥善保管，不要泄露给他人。

购买后如何将订阅导入 Quantumult？

当你手里有了订阅链接后，就可以进行关键的一步——将其导入 Quantumult X 中：

  1. 打开 Quantumult X，进入主界面。
  2. 点击右下角的“设置”图标（通常是一个齿轮状或三横线样式的按钮）。
  3. 在设置菜单中，寻找“配置文件”或“订阅”选项。在 Quantumult X 中，通常是通过“节点”或“资源”板块来管理订阅。
  4. 点击“添加”或“+”号，选择“服务器订阅”或“通过 URL 添加”。
  5. 将你从服务商那里复制的订阅链接粘贴到输入框中，点击“完成”或“保存”。
  6. Quantumult X 会自动从该链接拉取最新的服务器节点列表。稍等片刻，你就能在主界面的“节点”列表中看到大量的服务器名称了。

至此，你已经完成了从“购买应用”到“购买服务”并“导入配置”的全部关键步骤。

第三章：新手上路——基础使用与设置教程

当你成功导入订阅后，接下来就是激动人心的测试连接环节了。但别急，合理的设置能让你事半功倍。

1. 添加订阅链接与更新配置

在 Quantumult X 中，订阅管理是动态的。服务商可能会定期更换服务器 IP 或增加新线路。你需要定期手动下拉刷新或设置自动更新策略。

  • 手动更新：在“节点”页面的订阅卡片上，点击刷新图标即可强制拉取最新配置。
  • 自动更新：在“设置” -> “其他” -> “订阅管理”中，你可以设置自动更新的时间间隔（如每24小时），确保节点信息始终保持最新。

2. 配置代理模式与分流规则

Quantumult X 的强大之处在于其灵活的分流策略。它允许你指定哪些网站走代理（例如 Google、YouTube），哪些网站直连（例如国内视频网站、银行应用），从而在保证访问速度的同时，节省代理流量。

  • 全局模式：所有流量都经过代理。这种模式简单粗暴，但访问国内网站时速度可能会变慢。
  • 规则模式（推荐）：Quantumult X 内置了丰富的规则库。它会自动根据域名或 IP 判断是否走代理。你可以在“设置” -> “配置文件”中，选择或编辑现有的分流规则。新手可以直接使用默认的“分流规则”（通常带有“规则”字样），它已经能很好地平衡国内外网站的访问需求。
  • 在“设置” -> “代理”中，你可以选择代理的协议类型（如 Shadowsocks、VMess 等）。通常订阅导入后会自动识别，无需手动修改。

3. 启动连接与测试

完成上述设置后，回到 Quantumult X 的主界面。你会看到一个明显的“开关”按钮。

  1. 点击该按钮，系统会提示你允许添加 VPN 配置。请点击“允许”，并完成系统的指纹或密码验证。
  2. 启动成功后，状态栏会出现一个 VPN 图标（一个小钥匙或 VPN 字样），表示代理已生效。
  3. 此时，你可以打开 Safari 浏览器，尝试访问一个之前无法打开的网站（如 Google）。如果页面能正常加载，恭喜你，你的 Quantumult 已经成功工作了！

第四章：进阶提升——让 Quantumult 更懂你

当你掌握了基础连接后，可以尝试探索 Quantumult X 的进阶玩法，这会让你的使用体验更上一层楼。

  • 自定义界面：Quantumult X 提供了多种主题配色和图标风格，你可以根据自己的审美偏好进行个性化设置，让工具界面不再单调。
  • 多订阅管理：你可以同时添加多个不同服务商的订阅，并根据网络情况在它们之间快速切换，作为备用线路，确保网络永不中断。

第五章：常见问题解答与注意事项

在购买和使用过程中，你可能会遇到以下问题：

Q：Quantumult 和 Quantumult X 有什么区别？我该买哪个？ A：Quantumult 是较早的版本，功能相对基础。Quantumult X 是重写后的全新版本，界面更华丽，支持脚本、更灵活的分流规则，且持续更新。目前强烈建议购买 Quantumult X。如果你已经购买了旧版，可能需要再次付费购买新版。

Q：为什么我购买了应用，但连接速度还是很慢？ A：这通常与你的代理服务商（机场）的线路质量有关，而非 Quantumult 应用本身。你可以尝试切换订阅中的其他节点，或联系服务商寻求帮助。此外，你的本地网络环境（如 Wi-Fi 信号不佳）也会影响速度。

Q：免费试用期是多久？ A：关于免费试用，一般是指某些第三方代理服务商提供的试用套餐，而非 Quantumult 应用本身。Quantumult X 作为付费应用，在 App Store 下载时通常没有免费试用期，一旦购买即扣除费用。请勿混淆。

Q：如果忘记服务商网站的密码怎么办？ A：这与你购买 Quantumult 无关。你需要前往你购买代理订阅的服务商网站，通过其提供的“找回密码”功能进行重置。

支持。用户可以根据延迟或使用需求手动排序节点顺序，结合策略组和规则文件实现基本分流管理。虽然不支持自动订阅更新，但满足轻量用户的节点管理需求。
V2Ray 中的多入口（inbounds）配置有什么用？
V2Ray 支持多入口配置，可以同时开启 HTTP、Socks、TUN 等多种代理方式，方便不同程序接入。通过设置不同端口，用户可实现局域网共享或分离不同流量来源。
SSR 的混淆插件如何增强隐蔽性？
混淆插件可模拟正常协议特征，如 HTTP 或 TLS 流量，使 SSR 流量难以被检测。合理选择混淆方式和协议，可提升在高封锁环境下的长期稳定性和安全性。
Clash 的策略组如何提升分流效率？
策略组可以将多个节点或规则组合在一起，实现按条件自动选择最佳节点。通过策略组，用户无需手动切换节点即可根据延迟、地理位置或流量类型自动分流，提高网络效率。
VMess AEAD 加密如何确保数据安全？
AEAD 加密防止数据篡改、重放攻击和流量特征泄露。在高封锁环境下，保证节点可用，提升数据安全和连接稳定性，降低被检测风险，确保长期安全访问。
WinXray 的多出口节点如何优化访问速度？
通过为不同流量类型设置不同出口节点，WinXray 可以自动选择延迟最低的节点处理请求。结合策略组，可提高网页访问、视频播放和游戏等应用的速度与稳定性。
Nekoray 与 Nekobox 有什么不同？
Nekoray 是一款基于 Qt 的跨平台代理前端，而 Nekobox 更偏向移动端简化使用。两者均支持 V2Ray/VLESS/Trojan 协议，但 Nekobox 提供了更轻量的界面和更快的连接启动速度。
Surfboard 能否同步 Quantumult X 的规则？
Surfboard 的规则语法与 Quantumult X 相似，但并非完全兼容。部分策略组或脚本需手动修改格式方能正常使用，因此不建议直接复制，最好通过转换工具处理。
Clash 的 ACL4SSR 规则与 Rule Provider 有何区别？
ACL4SSR 是第三方规则集合，专注于分流国内外网站。Rule Provider 是 Clash 的订阅机制，允许自动更新远程规则。二者可以结合使用，实现灵活分流管理。
VLess 使用 XTLS 时证书怎么配置更安全？
推荐使用可信 CA 签发的证书（例如 Let's Encrypt），并为服务器配置正确的域名、SNI 与证书链。避免使用自签名证书或错误域名，以免被客户端拒绝或被中间人攻击检测到。
